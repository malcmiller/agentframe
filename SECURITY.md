# Security policy

## Supported versions

AgentFrame is pre-1.0. Only the latest published `0.x` release of
[`agentframe-py`](https://pypi.org/project/agentframe-py/) receives security
fixes; fixes ship in a new release rather than as patches to older ones.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/malcmiller/agentframe/security/advisories/new),
not in a public issue, pull request or discussion. Include the affected
version, the impact and the steps to reproduce it. Never include real
credentials, tokens or private data.

You will get an acknowledgement in the advisory. Once a fix is released, the
advisory is published with credit to the reporter unless you ask otherwise.
